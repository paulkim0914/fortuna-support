1. 앱에서 처리하는 정보
Fortuna는 무료 무작위 번호 생성 도구입니다. 회원가입, 로그인, 광고, 이용 분석, 위치 수집 기능이 없습니다. 앱은 번호와 설정을 운영자의 서버로 전송하지 않으며 별도의 서버를 운영하지 않습니다.

당첨 기록 분석 화면을 열면 공개 데이터 주소(https://smok95.github.io/lotto/results/all.json)에 새 회차 확인 요청을 보냅니다. 이때 통신에 필요한 IP 주소 등이 데이터 제공 서버에 전달될 수 있습니다. 사용자가 저장한 번호와 설정은 요청에 포함하지 않습니다.

2. 기기에 저장하는 내용과 목적
보관함에 저장한 번호 조합, 생성·저장 시각, 즐겨찾기 상태와 테마·추첨 효과 설정을 기능 제공을 위해 기기에 저장합니다. 온라인에서 확인한 당첨 기록도 회차 열람과 통계 제공을 위해 기기에 저장합니다. 저장 항목을 구별하기 위한 무작위 ID는 계정이나 광고 식별자가 아닙니다. 생성 결과와 고정·제외 선택은 앱 실행 중에 유지되며, 저장하지 않은 결과는 재실행 후 복원되지 않습니다.

3. 보관과 삭제
이전 개발용 시제품에서 가져온 CSV는 현재 분석에 사용하지 않으며 앱 저장소에 남아 있을 수 있습니다. 앱 데이터를 삭제하면 이 값과 자동 갱신 기록도 함께 삭제됩니다.
저장한 번호는 보관함에서 개별 삭제하거나 설정의 ‘보관함 모두 삭제’로 삭제할 수 있습니다. 보관함 삭제는 테마·효과 설정을 지우지 않습니다. 앱 삭제 또는 운영체제의 앱 데이터 삭제로 기기의 앱 데이터를 제거할 수 있습니다. 웹 미리보기에서는 브라우저의 사이트 데이터 삭제를 사용할 수 있습니다. 운영체제의 백업·기기 이전 기능에 따른 복사본은 해당 서비스의 설정과 정책을 따릅니다. 운영자는 이 복사본에 접근하거나 삭제할 수 없습니다.

4. 복사와 공유
사용자가 복사를 선택하면 번호 텍스트를 시스템 클립보드에 넣습니다. 공유를 선택하면 운영체제의 공유 기능을 통해 사용자가 선택한 앱에 번호 텍스트를 전달합니다. 클립보드 동기화와 수신 앱의 데이터 처리는 해당 운영체제·앱의 정책을 따릅니다. 운영자는 공유 대상이나 전송 내용을 서버에 기록하지 않습니다.
